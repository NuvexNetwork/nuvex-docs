# API

The HTTP API lives in [nuvex-services](https://github.com/NuvexNetwork/nuvex-services). It is a read model. `GET /health` returns `authority: none`. Collection routes under `/v1` return 501.

OpenAPI: `api/openapi.yaml` in that repository.

Websockets are disabled. There is no API key issuer.
