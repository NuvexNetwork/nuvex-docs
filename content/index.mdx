# Nuvex documentation

<span className="nuvex-status">Milestone 3</span>

Nuvex is a Solana protocol for verifiable jobs: randomness first, then data, computation, and only later inference.

A VRF request can be opened, cancelled, expired, or fulfilled with an ECVRF proof by an active node that meets the configured stake and heartbeat. Fees and weighted node assignment are not implemented. If a page says a feature is absent, there is no hidden code path that implements it.

## What is live

- On-chain VRF verification with `solana-ecvrf` 0.0.1
- Registry stake, heartbeat, and the eligibility predicate
- Cancel, expire, and VRF fulfill, including a callback with no accounts

## What is not

- Fees: `max_fee` is stored and never charged
- Weighted node assignment
- Price, data, compute, and inference jobs
- A node process that submits transactions
- Mainnet deployment
