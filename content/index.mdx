# Nuvex

Nuvex is a Solana protocol for verifiable jobs: randomness first, then data, computation, and only later inference.

This documentation matches Milestone 3. A VRF request can be opened, cancelled, expired, or fulfilled with an ECVRF proof by an active node that meets the configured stake and heartbeat. Fees and weighted node assignment are not implemented. If a page says a feature is absent, there is no hidden code path that implements it.
